# Mobile app

**Phase 7 · Scale · HubSpot equivalent: HubSpot mobile app**

## What it is

An Android and iPhone app with Today, leads, contacts, inbox, tasks and alerts as push notifications. Calls made from the
app are logged automatically; business cards can be scanned into contacts.

## Done when

- [ ] Published on both stores; push alerts arrive within seconds; works offline for reading recent records.

## For developers

- **Code folder:** `apps/mobile`
- **API:** [API.md](../API.md), Phase 7 → Mobile app
- **Code:** React Native or a wrapped web app (decide at the start of the phase), using the public API from Phase 5.
