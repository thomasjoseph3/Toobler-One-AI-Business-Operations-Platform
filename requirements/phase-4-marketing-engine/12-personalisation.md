# Personalisation

**Phase 4 · Marketing · HubSpot equivalent: Personalisation, Dynamic content, Smart content**

## What it is

Website and landing page sections that change for each visitor: returning customers see "Welcome back, Priya"; visitors
from an ad see that ad's offer; Malayalam speakers see Malayalam text.

## Done when

- [ ] Rules by source, segment, language and known contact show the right block.

## For developers

- **Code folder:** `apps/api/src/engines/marketing/personalisation`
- **API:** [API.md](../API.md), Phase 4 → Personalisation
- **Code:** rules on page blocks in `pages`; decided on the server to avoid flicker.
